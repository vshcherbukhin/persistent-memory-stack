# Navigation

The sidebar begins with the existing Persistent Memory logo and product name,
with **Community version** directly below it. Community has one personal knowledge
space; there is no space switcher or remote Shared Memories connector.

Choose Overview, Memories, Services, Workers, Token usage, Security, Notifications
or System Settings. The highlighted row is the current page. Documentation stays
near the bottom and your profile is last. Available configuration actions still
follow the validated local identity and existing permissions.

Security, Services and Workers show a red **!** when their live status needs
attention. Open the affected page to inspect actual findings or failed jobs.
A paused worker alone does not create an alert.

The top-right book opens help; the release icon opens version history. Existing
tooltips and keyboard controls remain available. Open **Your profile → Appearance**
to choose Obsidian, Porcelain or Match system. The same navigation remains usable
at narrower widths, including the Community label.

Historical `/connection`, `/grants`, `space=shared` and `surface=shared` URLs do
not activate sharing. Use a personal sidebar link to return to current navigation.

Project and topic filters organize your personal knowledge. Check explicit
filters before editing or deleting; selecting a project never changes ownership.
